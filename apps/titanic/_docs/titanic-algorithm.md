# 캐글 타이타닉 생존자 예측 추천 알고리즘 Top 5

캐글 타이타닉 생존자 예측 모델 훈련에 적합한 5가지 알고리즘 추천 및 분석 내용입니다.

기계 학습에서 특정 알고리즘 자체가 무조건 높은 정확도를 보장하지는 않습니다. 타이타닉과 같은 정형 데이터(Tabular Data)의 경우, 알고리즘의 선택보다 **데이터 전처리** 및 **특성 공학(Feature Engineering)**이 모델 성능에 훨씬 더 결정적인 영향을 미칩니다. 데이터의 내재적 노이즈로 인해 상위권의 현실적인 정확도 한계치는 대략 82%~84% 선으로 알려져 있습니다.

이러한 사실을 바탕으로, 타이타닉 데이터셋 구조에서 통계적으로 가장 우수한 성능을 도출하기 유리한 알고리즘 5가지를 정리했습니다.

---

## 타이타닉 추천 알고리즘 Top 5

### 1. XGBoost (eXtreme Gradient Boosting)
* **특징:** 캐글 정형 데이터 경진대회에서 가장 빈번하게 우승을 차지하는 트리 기반의 앙상블 모델입니다.
* **장점:** 자체적인 교차 검증, 결측치 처리 기능, 그리고 과적합(Overfitting)을 방지하는 규제(Regularization) 기능이 뛰어나 예측 성능이 매우 높습니다.

### 2. CatBoost (Categorical Boosting)
* **특징:** 범주형 변수(Categorical Feature) 처리에 특화된 알고리즘입니다.
* **장점:** 타이타닉 데이터에는 성별(Sex), 탑승항(Embarked), 객실 등급(Pclass) 등 범주형 데이터가 많습니다. CatBoost는 복잡한 원-핫 인코딩(One-Hot Encoding) 과정 없이도 내부적으로 범주형 데이터를 효과적으로 처리하여 높은 정확도를 냅니다.

### 3. Random Forest (랜덤 포레스트)
* **특징:** 수많은 의사결정 나무(Decision Tree)를 무작위로 생성한 뒤, 다수결 투표를 통해 최종 예측을 수행하는 모델입니다.
* **장점:** 구조가 직관적이고 복잡한 하이퍼파라미터 튜닝 없이도 기본 설정만으로 상당히 높은 정확도를 보여줍니다. 초기 베이스라인(Baseline) 모델을 구축할 때 가장 적합합니다.

### 4. LightGBM (Light Gradient Boosting Machine)
* **특징:** XGBoost와 유사한 부스팅 방식이나, 트리가 수직으로 확장되는 리프 중심(Leaf-wise) 분할 방식을 사용합니다.
* **장점:** 학습 속도가 매우 빠르고 메모리 사용량이 적습니다. 다만 타이타닉처럼 데이터 크기(행 개수)가 작은 경우 과적합의 위험이 있으므로, 트리의 깊이(max_depth)를 제한하는 등의 튜닝이 필수적입니다.

### 5. Voting Classifier (보팅 분류기 / 앙상블)
* **특징:** 단일 알고리즘이 아니라, 서로 다른 여러 알고리즘의 예측 결과를 종합하여 최종 예측을 내리는 앙상블 기법입니다.
* **장점:** 예를 들어 Random Forest, XGBoost, Logistic Regression 모델을 하나로 묶어 다수결(Hard Voting)이나 확률의 평균(Soft Voting)으로 결과를 냅니다. 개별 모델의 약점을 상호 보완할 수 있어 단일 모델보다 무조건적으로 더 높고 안정적인 정확도를 달성할 수 있습니다.

## 요약 및 개선 방향 제안

* **포인트 요약:** 트리 기반의 앙상블 모델(XGBoost, CatBoost, Random Forest 등)이 타이타닉 데이터에서 가장 높은 정확도를 낼 수 있는 핵심 알고리즘입니다.
* **개선 방향:** 처음부터 무거운 모델을 사용하기보다는 **Random Forest**로 초기 80% 수준의 기준점을 잡는 것을 권장합니다. 이후 파생 변수 생성(예: 가족 규모, 이름의 호칭 추출 등)을 거친 뒤, **XGBoost**나 **CatBoost**로 모델을 고도화하고, 최종적으로 이 모델들을 **Voting Classifier**로 결합하는 것이 상위권 달성을 위한 가장 표준적이고 효과적인 전략입니다.
